# Doom 3 RoE SABot FastDL

Client files for the SABot Alpha 7x instance of Vio's Arcade Doom 3:
Resurrection of Evil server.

Stock Doom 3: RoE 1.3.1 clients with downloads enabled can retrieve these
files automatically when joining. For manual installation, copy the contents
of `sabot-roe/` into a `sabot-roe` folder beside `Doom3.exe`, then launch with:

```text
Doom3.exe +set fs_game_base d3xp +set fs_game sabot-roe
```

SABot was created by Jarad "TinMan" Hansen. Its included readme permits
unmodified redistribution. This repository contains no retail Doom 3 or RoE
game assets.
